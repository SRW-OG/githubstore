# 安装功能

[项目说明](../README.md) · [启动器使用](LAUNCHER.md) · [架构](ARCHITECTURE.md) · [AI 使用](AI.md) · [验证记录](../DEVELOPMENT.md)

核对日期：2026-11-02，以下为本次交付版本 v0.1.22 的行为；当前安装包及旧版差异见 [产物状态](CHANGELOG.md#当前产物与验证边界)。

在排行榜或分类中打开软件详情，核对“选择下载包”，点击“安装所选包”。确认框列出软件、版本、安装包与实际目标目录，默认为 `C:\githubapps\<软件名>`。建议在首次安装前设置安装根；已有安装或正在安装时不能更换，目前不支持迁移。

## 浏览与添加仓库

Star 排行榜与分类列表使用每页 10 条，提供上一页、下一页、当前页与总页数；排行榜只在前 60 名快照内分页。切换分类、搜索条件或排序后回到第 1 页，普通目录的“加载更多”与趋势首页的来源榜单不按此规则分页。

从“软件源”添加公开仓库时，先填仓库地址和发行通道，再点整行强调色“获取预览”；预览成功后确认下载包、分类与规则，最后添加到目录。它添加的是可下载的软件目录条目，不是本地启动器入口。将本机 EXE/快捷方式加入启动器请使用 [手动添加](LAUNCHER.md#手动添加)。

设置入口固定在侧栏底部，并与可滚动分类区域分隔；设置内容区及底部提示居中，内容最大宽度 900 DIP，窄窗口仍可滚动。原生标题栏跟随当前深浅主题，高对比度下使用系统配色。

推荐按架构匹配后依次选择绿色压缩包、便携 EXE、普通 EXE、MSI。绿色包依据明确的便携命名，或与同一发行版 EXE/MSI 归一化同名的压缩包；`Setup`/`Install` 压缩包不作为绿色包。推荐只是默认选中，可手动改选。

## 安装方式

| 包类型 | 实际行为 |
|---|---|
| ZIP | 下载校验后，在安装根的独立暂存目录安全解压，核验入口再移动到目标目录 |
| 便携 EXE | 按明确类型或便携命名规则识别，复制到目标目录，不作为安装器执行 |
| EXE 安装包 | 打开交互式向导，不猜通用静默参数；请在向导中选择确认框所示目录，可能出现 UAC |
| MSI | 使用系统 `msiexec.exe /i <安装包> /norestart` 打开向导；从包内读取公开安装目录属性和 ProductCode，能确认时预填目录，否则请手动选择 |
| 7z | 暂不支持自动解压，在下载前明确拒绝。旧系统 tar 路径不能在写盘前可靠限制链接与展开量，现已移除；请手动选择 ZIP 或 EXE/MSI，不会自动换包 |

MSI 的目录属性来自实际数据库，例如 KeePassXC 的 `INSTALL_ROOT`，读取失败时不猜属性名。EXE/MSI 都没有通用强制目录能力，也不会自动重启 Windows。

若多个主程序候选无法明确匹配软件名，会提示选择相对路径。目标内存在有效 EXE 后才写成功回执，并在“启动器”显示入口图标；不创建 Windows 桌面 `.lnk`。PE 格式核验不代表签名或安全认证。

## 启动器入口与图标

启动器同时显示商店成功安装入口与手动添加入口。可选择或拖入本机 `.exe` / `.lnk`，确认名称、分类和参数后添加；快捷方式自动读取实际 EXE 路径与原有参数，保存后直接启动实际程序。手动入口独立存储，不生成商店安装回执，也不自动成为托管“已安装”项目。winget 独立安装不会自动加入，但可以自行手动添加其入口。

卡片为 128×128 DIP 正方形，商店条目使用主题默认样式，手动条目默认青色背景；各分类按成功启动次数降序排列、同次数按名称排序。右键“属性”只显示程序路径和参数，商店路径只读；手动条目路径和参数一起原子保存，旧 `.lnk` 在编辑保存时转换。右键移除手动条目仅删除入口记录，保留原文件。操作、重复项规则、旧高级配置兼容与故障处理见 [启动器使用说明](LAUNCHER.md)。

商店默认无参数启动会观察进程前 4 秒，期间异常非零退出显示失败；零退出可能是单实例转交，不直接认定失败。手动启动及带参数、目录或管理员选项的自定义启动使用 Shell 执行，不套用同一观察结论。启动服务返回成功后才累计次数，仍不能据此保证程序已完成初始化或持续运行。

图标优先只读 EXE 中原生 `RT_GROUP_ICON`/`RT_ICON` 资源，选择应用图标组和最佳尺寸帧，再交给 WinUI 解码；不运行软件、不加载目标程序集。无法读取时依次尝试 Windows Shell 图标、WinRT 缩略图和通用字形；Shell 图标也支持旧 `.lnk`。历史自定义图标仍兼容读取，但当前属性窗口没有图标编辑控件。

真实 DevToys/KeePassXC 图标提取已核对。2026-10-25 14:25（Asia/Shanghai），用户实机确认了当时版本的基础验收与 DevToys 启动问题解决；该历史确认不替代 2026-11-02 新属性界面的验收，本次也没有新增该崩溃问题的根因判定或修复。

## winget 独立安装

在“软件源”页，顶部可以添加 GitHub 仓库；下方提供 winget 搜索，左侧显示结果，右侧显示选中包的实时详情。内置精选不代表实时版本，详情中的缺失字段会如实显示未提供。详情按精确包 ID 运行 `winget show`，只查询 `winget` 来源，兼容 CLI 英文/中文字段及多行说明；即使清单内容指定 `en-US`，本地 CLI 标签仍可能是中文。

核对右侧包名和包标识后，点击“通过 winget 安装”。软件的原生安装向导可能随之打开，机器级安装可能请求 UAC。命令为：

```text
winget install --id <ID> --exact --source winget --accept-source-agreements --accept-package-agreements --interactive --disable-interactivity
```

安装目录、用户/机器范围由 winget 和原安装器决定。此流程不传 `--location`、`--scope`、`--force`、`--silent`，不强制放入 `C:\githubapps`，也不登记到商店启动器或受管安装流水。它不使用本应用的 `packages-v1` 下载缓存；下文的 GitHub 包目录、缓存、入口核验和商店升级/回退规则不适用于这条流程。

一次只运行一个 winget 安装；并发请求返回忙。安装限时 30 分钟，界面显示不定进度状态，可取消。取消或超时时，进程执行器尝试终止拥有的进程树；提权或脱离进程树的安装器仍可能继续，不能据此认定已回滚，请检查安装向导和 Windows 已安装应用。此行为与 GitHub 安装服务对外部安装器“停止等待”的策略不同。

只有 CLI 正常退出且原始退出码为 `0`、`3010` 或 `1641` 时报告成功，后两者显示需要重启；不自动重启 Windows，不将其他 winget HRESULT 猜测为成功。结束后可展开本次输出，最多 8,000 字符并清除 ANSI 控制序列；不是实时日志，也不提供实际百分比进度。

命令、错误分类、并发与取消已有模拟进程回归；0.1.14 本轮真实使用验收已由用户于 2026-10-25 14:25（Asia/Shanghai）确认通过。本次未新增代理安装实测，也未逐项确认超时、UAC 拒绝、取消、重启状态或跨设备/安装器矩阵，这些扩展场景仍待补充。winget 安装的软件请使用 Windows 或其自身的管理入口；本商店尚未提供 winget 已安装列表、更新与卸载。

## 下载缓存

“仅下载”和“安装”共用持久安装包缓存，先下载后安装可以复用同一文件。默认缓存根是应用数据目录下的 `cache`（通常为 `%LOCALAPPDATA%\GitHubStore\cache`，随 `GITHUBSTORE_DATA_DIR` 改变），也可在设置中保存自定义根。

实际文件位于 `<缓存根>\packages-v1\<完整来源URL的SHA256>\<文件名>`。复用时重新校验大小和摘要：有上游 SHA-256 时核对上游值；没有时核对本地 SHA-256 回执，不能只凭文件名复用。本地回执只能确认缓存字节未变化，不能证明发布者身份。

已完成安装包持续保留，没有过期或容量自动淘汰。校验失败的旧完整包会改为 `retained-invalid` 名称保留，再尝试下载；中断传输可能保留 `.part` 和断点元数据。

在“设置”的已保存缓存路径下点击“清空全部下载缓存”，确认后清除本应用 `packages-v1` 命名空间内的完整包、保留旧包、未完成文件与校验文件，没有逐包选择。下载和安装器使用缓存期间持有租约，此时清理会提示忙，请任务结束后重试。清理失败会报告跳过或残留，不把失败显示为已清零。

清空不会删除自定义根本身、根中的其他文件、已安装软件、README/AI/趋势缓存或密钥设置。没有本应用命名空间标记的历史自定义缓存目录不会自动清理。保存新根只改变后续操作使用的位置，不移动或删除旧缓存；需要清理旧根时，应先切回并保存该路径。

## 失败、取消与目录保护

已有目标目录或软件登记会阻止**首次安装**，避免覆盖。

## 升级与回退（绿色/便携安装）

“已安装”页使用单列列表，每行直接显示当前版本、最新版本与“卸载 / 更新 / 回退上一版本”按钮。版本查询与操作状态按条目管理；无可用候选或不支持对应操作时会给出状态或错误提示。

本程序解包安装的绿色/便携应用支持升级：下载并校验新包、解压到隔离暂存目录、核验入口后临时挪开旧目录、切换新版本，并以**同一个安装 ID** 更新回执。更新中的 journal 与临时旧目录用于失败/中断恢复；成功提交后清理旧目录，不再保留一整份可供用户直接选择的上一版本备份。清理或恢复失败会提示残留，不保证任意文件系统故障下都已恢复成功。启动时发现中断 journal 会先尝试恢复或清理，失败时提示人工核对。

回退由用户点击“回退上一版本”显式触发：从该应用的软件源查询**比当前版本更旧的最近一版**及受支持安装包，优先使用已校验下载缓存，未命中再下载，然后执行同一受管替换流程。它不依赖本地完整旧目录，也不保证回到用户曾经安装过的那个版本；源中无更旧候选、版本不可判定或安装包不支持时会提示不可回退，联网与上游包可用性仍可能影响操作。

普通 EXE/MSI 安装器安装的应用**不**走这条升级路径：请使用软件自身的升级机制。受支持的便携 EXE 与普通 EXE 安装器不同。当前不支持增量/差分更新、7z 升级、声明 `PreservePaths` 的保留式更新、用户数据迁移或目录迁移。

下载或解压取消会停止当前任务并清理其独占安装暂存目录，完整安装包仍保留。外部安装器启动后，“取消”只停止等待，不强杀安装器，也不代表回滚；请检查其向导和 Windows 已安装应用。

安装器可能忽略所选目录、提前退出或不支持自定义目录。目标目录中没有可核验的入口时，不登记为成功。文件已提交但登记失败时保留文件并提示可能残留，请先检查目录权限和现有安装，避免反复覆盖。

## 删除（移除）已安装应用

在“已安装”页选中应用后点击“卸载”，根据安装方式处理：

- **本程序解包的 ZIP / 便携 EXE**：按安装回执确认所有权，校验受管根的直接子目录并拒绝路径穿越、重解析点等，再先撤登记、后删除该目录。中途失败会提示残留；不清理目录外的用户数据。
- **EXE / MSI 安装器安装**：从 Windows HKLM/HKCU 的 32/64 位注册卸载项中，按精确安装目录和归一化名称唯一匹配。MSI 使用系统 `msiexec /x <注册产品码> /norestart`，保留交互界面；旧回执没有 ProductCode 时也可由注册项匹配。EXE 仅使用经过校验的注册卸载命令。机器级应用会请求 UAC。

拒绝 UAC、取消或卸载失败会保留安装登记；只有确认对应 Windows 注册项已消失，才移除商店回执。卸载器提前返回而注册项仍在时，不宣称已经卸载完成。匹配缺失或不唯一时，请使用软件自己的卸载器或 Windows“已安装的应用”。

## 数据与校验

安装使用选中资产的来源快照、大小和可选 SHA-256，完成下载后独立复核。成功回执保存在数据根 `managed-apps.json`，含软件/资产身份、版本、目录、入口、计算摘要与完成时间；可读取时另存 MSI ProductCode。

手动启动器条目另存 `manual-launcher.json`，名称、分类、实际程序路径和参数等不授予安装/卸载所有权。`launcher-customizations.json` 保存按来源与 ID 区分的启动次数、商店启动参数和历史自定义选项。三份记录职责分离；手动添加、修改参数或移除入口不会改写商店安装回执。默认数据根和兼容读取规则见 [启动器数据说明](LAUNCHER.md#移除与数据保存)。

ZIP 解压拒绝路径穿越、绝对路径、ADS、保留名称、尾随点/空格、大小写重复路径、符号链接和重解析点；最多 10,000 条目、2 GiB 展开量。清理安装暂存只针对本次创建的目录，不清空安装根。

实现见 [安装服务](../src/GitHubStore.App/Services/Installation/AppInstallService.cs)、[缓存服务](../src/GitHubStore.App/Services/Download/PackageCacheService.cs)、[Windows 注册卸载](../src/GitHubStore.App/Services/Inventory/RegisteredUninstallService.cs)。具体实机证据见 [开发与验证](../DEVELOPMENT.md)。
