# 启动器使用说明

[项目说明](../README.md) · [安装与更新](INSTALLATION.md) · [架构与数据](ARCHITECTURE.md) · [开发与验证](../DEVELOPMENT.md) · [近期更新](CHANGELOG.md)

核对日期：2026-11-02，本文描述本次交付版本 **v0.1.22** 的程序行为。该版本已生成 Windows x64 自包含安装包，包含手动添加、正方形卡片、精简属性、快捷方式解析和原子参数保存。0.1.21 是早期完整属性编辑阶段的本地安装包，未单独公开发布；当前使用方式以 v0.1.22 为准。

## 应用从哪里来

| 来源 | 如何加入 | 默认外观 | 与安装管理的关系 |
|---|---|---|---|
| 本程序安装 | 经 GitHubStore 安装并成功登记后自动出现 | 跟随主题的默认卡片 | 由成功安装回执管理，适用其自身安装方式的卸载、更新规则 |
| 手动添加 | 选择或拖入本机 `.exe` / `.lnk`，确认后保存 | 青色背景和边框 | 只是启动入口，不生成安装回执，不自动出现在托管“已安装”列表 |
| winget 独立安装 | 不自动加入；如需展示，可以另行手动选择实际 EXE 或快捷方式 | 手动添加后按手动条目显示 | 手动加入不会将 winget 软件变为商店受管安装 |

卡片为 **128×128 DIP** 的正方形，图标和名称居中，长名称最多两行并截断。DIP 为逻辑尺寸，物理像素会随 Windows 显示缩放变化。不显示“手动添加 / 本程序安装”的来源文字徽标；来源由默认卡片样式区分。旧配置中已有自定义颜色时，仍优先使用该颜色。

## 手动添加

1. 进入“启动器”，点击“手动添加”，选择本机 `.exe` 程序或 `.lnk` 快捷方式；也可以直接把支持的文件拖入页面。
2. 选择快捷方式时，程序只读取其目标与参数，不执行快捷方式；对话框显示解析后的实际 EXE 路径，并带入原有参数。
3. 确认应用名称、分类和参数后点击“添加到启动器”。默认名称保留所选文件的名称，未选分类的条目放在“其他”。
4. 保存后即可点击卡片启动，也可右键选择“启动”。

多文件拖入时逐个确认，取消当前添加会停止后续尚未确认的文件。添加过程不复制程序、不下载软件，也不创建 Windows 桌面或开始菜单快捷方式。

只接受本机有效路径，拒绝 UNC、设备路径、路径穿越、重解析点等不支持的入口。快捷方式必须能解析到存在的本机 EXE；指向网页、目录、脚本或缺失文件的快捷方式不能作为新入口保存。损坏或循环引用的快捷方式会报告错误；解析链最多 8 层。

**重复项按实际程序路径判定，忽略路径大小写。** 同一 EXE 的两个快捷方式，即使参数不同，也不会新增为两张卡片；已有条目的名称、分类和参数保持原样。若要修改其参数，请编辑已有条目。

## 编辑程序路径和参数

右键卡片选择“属性”。当前编辑器只显示两项：

| 字段 | 手动条目 | 本程序安装条目 |
|---|---|---|
| 程序路径 | 可输入新路径，或点“选择文件…”选择 EXE / 快捷方式 | 只读，启动入口始终来自安装回执 |
| 参数 | 可编辑或清空 | 可编辑或清空 |

编辑会保留原有名称、分类、条目 ID、添加时间和启动次数；当前属性框不提供重命名、改分类、图标、颜色、工作目录、管理员运行、快捷键或备注的编辑控件。名称与分类在手动添加时确认。

选择新快捷方式后，路径框填入实际 EXE，参数框替换为新快捷方式的自带参数；切换到普通 EXE 时自带参数为空，需要时可自行填写。取消文件选择或解析失败不会覆盖原输入。

已有旧版 `.lnk` 条目打开属性时会解析目标，并按“快捷方式自带参数 + 旧条目的额外参数”预填。点击保存后才把入口转成实际 EXE；仅打开属性或取消不会迁移记录。旧快捷方式损坏时仍可打开编辑框，浏览选择新程序修复。尚未编辑保存的旧 `.lnk` 条目继续沿用原有 Shell 启动方式。

参数直接交给选定程序，不通过 `cmd.exe` 或 PowerShell 解释。含空格的参数值应按目标程序的要求加引号，例如：

```text
--profile "D:\My Profiles\work.json" --port 8080
```

不需要在参数中重复填写程序路径。参数最多 8192 个字符，不允许 NUL 字符。参数是否被目标软件接受由该软件决定；保存成功不等于软件认识这些参数。

手动条目的实际路径与参数在同一个记录文件中原子保存；写入失败时原记录保持不变。参数清空保存后会明确记为空字符串，重启不会重新取回旧参数。商店安装条目的参数另存为启动器配置，不改安装回执。

## 分类、搜索与启动次数

- 商店条目的分类通常来自软件目录；手动条目的分类来自添加时的选择，旧版保存的分类覆盖仍兼容读取。
- 分类顺序跟随目录，未分类放在“其他”；每组显示数量和“按启动次数排序”。
- 各分类按成功启动次数降序排列；次数相同按当前语言环境中的名称排序，再以来源、条目 ID 保持稳定顺序。
- 搜索匹配名称及程序身份/路径，显示筛选后的数量；手动刷新重新读取本地入口与目录分类。
- 每次启动服务返回成功后累计一次，并立即更新排序；失败不增加。首次启用计数时从 0 开始，不回溯历史启动。
- 计数与来源、条目 ID 一起保存。两种来源即使 ID 相同也互不串用；计数写入失败时保留启动成功结果，并提示计数未保存。

“成功启动”表示启动服务返回成功，不保证程序已完成初始化或一直运行。商店条目的默认无参数启动有前 4 秒异常退出观察；自定义参数/目录/管理员启动与手动启动使用 Shell 执行，不能把该观察范围推广到所有入口。

## 图标与旧版高级配置

默认图标依次尝试 EXE 原生高分辨率图标、Windows Shell 图标、WinRT 缩略图和通用占位字形。资源读取不会执行目标程序；读取失败不阻止条目显示。Windows Shell 读取也支持尚未迁移的旧快捷方式。

0.1.21 本地安装包曾提供完整属性编辑，后续按需求精简为路径和参数。为兼容已有数据，以下能力仍保留后端读取与运行逻辑，但**当前属性窗口不再提供编辑入口**：

| 旧字段 | 当前兼容行为 |
|---|---|
| 自定义图标 | 图标文件有效时优先显示，失败回退程序图标；支持 ICO、PNG、JPG/JPEG、BMP 及可由 Shell 读取的图标来源 |
| 自定义颜色 | 覆盖默认卡片颜色，历史格式为 `#RRGGBB` / `#AARRGGBB` |
| 工作目录 | 仍用于自定义启动，指定目录不存在时启动报错 |
| 管理员运行 | 仍通过 `runas` 请求 UAC，取消授权不计为成功启动 |
| 全局快捷键 | 按旧配置尝试注册，仅本程序运行期间有效，窗口关闭时释放；不提供新的快捷键编辑控件 |
| 备注 | 保存在旧配置中；不显示在卡片或卡片提示中，当前窗口也没有备注编辑控件 |
| 旧名称/分类覆盖 | 保留显示，不因精简编辑而清空 |

快捷方式转换只读取程序目标与启动参数，不复制快捷方式自身的工作目录、管理员标志、图标或快捷键。不要把这些旧版兼容字段当作当前仍能从属性窗口设置的新功能。

## 移除与数据保存

右键手动条目选择“从启动器移除”，只删除启动入口记录，保留实际程序、原快捷方式及其目录。重新添加会获得新的条目 ID，旧 ID 的计数不会自动继承。商店安装条目的卸载使用“已安装”页，不能把手动入口当作删除软件的所有权凭证。

默认数据根为 `%LOCALAPPDATA%\GitHubStore`；开发和测试可用 `GITHUBSTORE_DATA_DIR` 覆盖。

| 文件 | 职责 |
|---|---|
| `managed-apps.json` | 商店成功安装回执与可信入口；手动添加不写入此文件 |
| `manual-launcher.json` | 手动条目的 ID、名称、实际路径、分类、添加时间与参数；路径和参数一起提交 |
| `launcher-customizations.json` | 按来源 + ID 存储启动次数、商店参数，以及历史显示/高级选项 |

旧手动记录缺少 `arguments` 或其值为 `null` 时，继续兼容读取历史自定义参数；明确的 `"arguments": ""` 表示已清空，不再回退。记录损坏时报告错误并保留原文件，不自动以空清单覆盖。更多结构、容量与调用链见 [架构与功能现状](ARCHITECTURE.md)。

## 验证与常见问题

2026-11-02：Debug x64 应用与测试项目构建均为 0 警告、0 错误，1908 项回归通过；本次交付另完成 Release x64 测试项目构建与 **1908 项测试通过、0 失败、0 跳过**，以及 Release 自包含发布和 Inno Setup 打包。新增用例包含真实 Windows 快捷方式、中文路径、引号参数、嵌套与无效目标、旧条目转换、参数清空后重载、启动传参及原子写入失败保留原记录。报告路径与复现命令见 [开发与验证](../DEVELOPMENT.md)。

v0.1.22 自包含发布文件已用独立数据目录进行启动检查，主窗口正常响应并正常关闭，退出码为 0；这不是安装向导全流程或最新属性窗口的点击验收。此前自动化未能读取开发窗口内部控件，最新属性窗口的点击与截图验收仍待补充。旧版卡片截图不替代该验证。

- **参数保存后无效果**：确认填写的是参数而不是程序路径，并查目标程序的参数规则；已打开的单实例软件可能自行忽略新参数。
- **找不到程序或快捷方式无效**：选择实际 EXE，或在旧条目的属性里浏览更换路径。程序文件不可用不会自动删除记录。
- **手动添加后“已安装”没有条目**：这是独立启动入口，不是安装回执，属于预期行为。
- **安装包中还是完整属性窗口或长方形卡片**：检查是否仍在使用旧 0.1.21 本地安装包或旧开发实例；本次 v0.1.22 安装包已包含精简编辑、方形卡片和快捷方式解析。
