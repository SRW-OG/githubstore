## 0.1.22 — 手动启动器、方形卡片、精简编辑与快捷方式解析（2026-11-02）

- 累计加入本地 EXE/快捷方式的选择或拖拽添加、独立手动入口存储、来源配色、成功启动次数排序、Shell 图标读取及右键启动/移除。手动入口不加入托管“已安装”，移除不删除原文件。

- 启动器卡片从 124×132 改为 **128×128 DIP 正方形**，调整图标上下间距，保持图标和名称居中。
- 右键“属性”精简为**程序路径与启动参数**。手动条目支持路径输入和文件浏览；商店安装条目路径只读，入口仍由安装回执决定。编辑保留条目身份、名称、分类、添加时间和启动次数。
- 选择或拖入 `.lnk` 时读取真实 EXE 路径及原有参数；不运行快捷方式、不自动搜索移动后的目标。支持中文路径与引号参数，拒绝无效/循环/过深快捷方式链、非本机或不支持的目标。
- 已有旧 `.lnk` 条目在打开属性时解析，保存时转为实际程序路径；自带参数与原有额外参数按顺序带入。损坏旧条目仍可通过浏览更换程序。
- 手动条目的路径与参数在 `manual-launcher.json` 内一次原子提交，避免先更新路径、后写参数失败造成部分保存。参数允许清空；缺省/`null` 兼容旧自定义参数，空字符串明确覆盖旧值，重启不恢复旧参数。
- 重复添加按实际路径去重，保留原条目参数；手动条目继续独立于商店安装回执和托管“已安装”列表。
- 早期完整属性编辑中的图标、颜色、工作目录、管理员运行、快捷键和备注数据仍保留兼容，当前编辑器不再提供这些控件。现行操作与兼容边界见 [启动器使用说明](LAUNCHER.md)。
- 真实快捷方式测试使用 Unicode 原生 Shell 接口创建夹具，避免 Windows Server CI 的 `WScript.Shell.TargetPath` 在中文路径赋值阶段失败；保留中文路径、引号参数等全部用例，不改变应用启动逻辑。

**验证：** 2026-11-02 Debug x64 应用/测试项目构建 0 警告、0 错误，1908 项回归通过；本次交付另完成 Release x64 测试项目构建（0 警告、0 错误）、**1908 项测试通过、0 失败、0 跳过**、Windows x64 自包含发布与 Inno Setup 安装包生成。新增覆盖真实 Windows 快捷方式、中文与引号参数、实际路径持久化及启动传参、旧条目迁移、清空后重载和写入失败保留原数据。v0.1.22 自包含发布文件在隔离数据目录下实际启动，主窗口正常响应并正常关闭（退出码 0）。尚未完成最新属性窗口点击/截图和安装向导全流程验收；构建、启动检查与单元测试不替代这些验证。
