## 0.1.15 — 软件目录同步合并与目录更新（2026-10-27）

- 目录同步时，若远端库已收录你手动添加的同一仓库，两条记录自动合并为一条，并以远端条目为准：仓库元数据、策展说明、分类归属与策略取远端，手动标记取消，之后远端更新可直接生效。
- 首次合并保留你自己设置过的描述覆盖与多分类选择；远端未收录的手动仓库照常保留。
- 同步结果新增合并数量，设置页据此提示“其中 N 款此前手动添加，已改用远端条目”。
- 随包与共享软件目录由 70 款更新为 80 款（新增 11 款、移除 TTime），补充文件管理、教育科学等分类内容；VeraCrypt 归入“安全隐私”。
- 修正设置测试对系统界面语言的依赖，并更新近期用户验收记录。

**已知限制（源码路径核对）：** 手动条目并入远端目录后，自定义描述与多分类选择仅在首次合并时保留；后续再次同步同一仓库会改用远端内容，重启不会恢复原有本地设置。

**开发阶段验证：** 1752 项测试通过（新增 3 项同步去重用例，并更新手动条目、选包策略两处既有用例的合并语义）；Windows x64 Release 构建通过。本次发布验证结果见文末。

## 0.1.14 — 启动器应用图标

- 启动器优先读取程序 EXE 中的原生图标资源，不再只依赖 Windows 缩略图缓存。
- 支持数字与字符串命名的图标组、语言变体和多分辨率图像。优先应用图标组并选取高分辨率帧，避免误选 KeePassXC 的数据库文件图标。
- 解析使用 PE 数据读取，不加载或执行目标程序。缺少或损坏资源时返回失败，再尝试 Shell 缩略图及本地占位图。
- 图标资源读取在后台进行，界面用绑定版本检查防止异步结果串到另一个条目。

**验证：** 1750 项测试通过；Windows x64 Release 构建及自包含安装包生成成功。修复代码从本机真实 DevToys EXE 提取出 512×512 紫色 PRE 图标，从 KeePassXC EXE 提取出 256×256 绿色钥匙图标，均已解码并查看。后续用户已确认近期版本验收完成。

**DevToys 状态：已解决（用户确认）。** 原 WebView2 `0x800700AA` 启动问题不再列为当前未解决项；解决机制未另行核实，不将其归因于图标读取修改。

## 0.1.13 — 独立 winget 安装与页面重排

- “添加软件源”位于页面顶部；winget 搜索、列表、详情和安装集中在下方。
- 点击右侧“通过 winget 安装”后，以精确包 ID 调用 winget，限定 `winget` 来源。原安装器可显示交互式安装界面和 Windows 权限提示。
- 不传入安装目录、用户范围、强制安装或静默安装参数。软件使用原安装器的默认位置或它提供的自选位置；不受 GitHubStore 托管安装根限制。
- 不写入 GitHubStore 成功安装回执，不加入启动器或托管“已安装”列表，也不走商店下载队列和 `packages-v1` 缓存。
- 增加执行中状态、重复任务防护、取消、退出码及结束后的执行结果查看。输出清除终端控制序列并限制长度；没有虚构下载百分比或实时日志。
- 任务超时为 30 分钟；取消或超时会尝试终止所持有的进程树，但不保证撤销安装器已作出的更改，也不能保证已提权或脱离进程树的安装器被终止。

**验证：** 1740 项测试通过。开发阶段安装命令、并发防护、成功/失败、取消与输出通过模拟进程测试，当时未实际安装第三方 winget 软件；后续用户确认近期功能验收完成。不同设备、不同安装器、UAC 拒绝、超时和卸载等扩展场景仍按路线图独立验证。

## 0.1.10 — 启动失败反馈

- 启动器创建进程后异步观察前 4 秒；窗口初始化阶段异常退出且退出码非零时，报告启动失败。
- 观察期内保持启动任务未完成，拦截重复点击。正常退出码 0 允许程序转交给现有实例，不一律作为失败。
- 不再把“创建了进程”当作“程序已正常打开并持续运行”的证据；观察期后的崩溃仍不能由此机制全部识别。

**当时验证：** 1686 项测试通过。DevToys 当时仍发生 WebView2 `0x800700AA` 异常；本版修复的是误报反馈。后续用户已确认该启动问题解决，见本文开头的验收确认。

## 0.1.9 — 每周 Star 刷新

- Star History 将每周排行移到页面引用的 JavaScript 资源后，增加从首页发现同源脚本、读取其中排行数据的路径。
- 只读取数据，不执行脚本；保留响应大小、来源身份、统计周期与指标校验及旧数据回退。
- 兼容源站当时使用的内联变量结构；后续源站改名或再次改版仍可能需要调整解析器，不宣称可以自动适应所有改版。

**验证：** 1686 项测试通过；当时真实界面显示源站周期 Oct 16–22、20 条记录，首项 `morluto/rea` 当周新增 91,729、累计 370,735。这是当时的验收数据，不是固定的当前排行。
