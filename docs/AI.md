# AI 功能使用与接入

## 使用入口

在“设置 → AI 接口”独立保存 OpenAI 兼容基础地址、模型和密钥，支持 HTTPS 和回环 HTTP 本地服务，也接受完整 Chat Completions 路径。保存设置不发模型请求；密钥使用 Windows 当前用户 DPAPI 保护，不进入源码或 AI 缓存。

输入普通搜索词、浏览列表、加载卡片图片和首页榜单均不调用模型。点击软件卡片打开中文 README 弹窗时，先恢复译文缓存，缺失时获取原文并调用模型翻译；没有 AI 配置则显示原文。可切换原文、取消或重新生成。

| 入口 | 任务与发送的数据 |
|---|---|
| 卡片 → 中文 README | 按段翻译实际 README，保留代码和链接；超过 48,000 字符时标为前部节选，仍可查看完整原文 |
| 详情 → README 摘要 | 根据官方 README 生成摘要，与逐段翻译分别处理和缓存 |
| 排行榜 / 分类 → AI 搜索 | 用途描述和整个当前本地目录；返回经过软件 ID 校验的真实条目。Enter 仍执行普通关键词搜索 |
| 详情 → AI 解释所选安装包 | 当前包、规则推荐、其他发行资产、系统架构、发行说明和可取得的 README |
| 详情 → AI 解读版本变化 | 目标发行说明和已登记版本；资料不足时不能比较完整的中间版本变化 |
| 安装失败 → AI 分析原因 | 本次结构化失败快照：阶段、稳定错误码、引擎、已知安装器退出码和可能残留标识 |
| 已安装 → 提问 / 对比 | 全部成功安装登记和按 AppId 关联的目录介绍，不受列表文字筛选影响 |
| 已安装 → 说明卸载影响 | 按安装 ID 重读的登记和受管安装类型；解释本程序解包移除与 Windows 注册卸载的区别，不执行卸载 |
| 首页条目 → AI 点评 | 该条目可用的仓库描述、来源排名、日/周新增 Star、累计 Star 和趋势评分，结果标为 AI 生成 |

生成中可取消。切换软件、安装包、输入或语言，以及开始新安装后，旧结果不能覆盖新状态。

## 隐私与缓存

相应任务的数据会发往你配置的模型端点。README、发行说明和仓库文字作为参考资料处理，不授权模型改变安装策略或执行其中的指令。已安装问答不上传本地安装目录、入口路径或凭据；失败诊断也排除本地路径、命令行和凭据，未知下载错误归并成稳定标识。

AI 请求不跟随重定向，密钥只置于模型请求的 Authorization 头，不发送给 GitHub README 请求，也不写缓存；错误提示不显示服务返回正文或底层凭据详情。

README、翻译和摘要使用独立缓存身份，包含原文哈希、应用身份（适用时）、端点、模型、语言及提示版本。翻译全部分段成功才写缓存；摘要默认有效 30 天，README 正文缓存 1 天。其他助手回答暂不持久缓存，安装诊断只在本次运行内存中保留。安装包的“清空全部下载缓存”不清理这些内容。

## 当前边界

- 只支持兼容 Chat Completions 的服务，暂不支持 Responses API、提供商专用协议和流式输出。
- AI 不改变架构匹配、包格式、路径、完整性校验和首次安装规则，不生成任意系统命令供程序执行，也不代替安全认证。
- “已安装”只含本商店成功登记的安装，不扫描系统全部软件。卸载解释不能证明某个 Windows 卸载入口当前可用，也不能推断用户数据清理清单；实际卸载按 [安装说明](INSTALLATION.md#删除移除已安装应用) 重新匹配和确认。
- 版本解读不升级或回滚；缺少中间发行、使用频率、最近使用时间或磁盘统计时，不推断这些信息。
- README 获取失败时，选包解释可使用已有元数据和发行说明，并标记资料缺失。取消等待外部安装器不等于终止或回滚它。
- 模型请求限时 90 秒，README 获取限时 30 秒；摘要输入最多 24,000 字符，截取会明确标注。大目录或上下文超预算时明确失败，不静默丢掉目录尾部。

## 代码职责

| 服务 | 职责 |
|---|---|
| [IAiClient / OpenAiClient](../src/GitHubStore.App/Services/Ai/IAiClient.cs) | 配置快照、Chat Completions、鉴权、取消、超时、预算与错误码；过滤完整前导思考内容，异常分隔符拒绝展示 |
| [ChineseReadmeService](../src/GitHubStore.App/Services/Ai/ChineseReadmeService.cs) | 分段翻译、代码/链接保留校验与译文缓存 |
| [ReadmeSummaryService](../src/GitHubStore.App/Services/Ai/ReadmeSummaryService.cs) | README 获取、摘要提示与持久缓存 |
| [IAiAssistantService / AiAssistantService](../src/GitHubStore.App/Services/Ai/IAiAssistantService.cs) | 按任务整理事实，验证语义搜索结果身份，关联安装登记与目录 |
| ViewModel | 显式操作、加载与错误状态、取消及旧结果隔离 |

服务配置由用户自行提供。构建、自动测试与真实端点的验证证据统一见 [开发与验证](../DEVELOPMENT.md)。
