# 软件管理优化实施记录

## 当前轮次：0.1.7 发布后可靠性优化

用户已授权继续优化。上一轮的“八项全部完成”结论过强：测试与编译通过不能证明界面接通、故障恢复或真实安装已验收。本轮以实际代码审查、针对性回归与界面验收为准。

### 已确认的问题与处理

- 下载队列：后台事件直接修改 ObservableCollection 和界面属性；原“仅下载”仍走单次下载，模板跨名称作用域取父命令，任务对象没有 Text 属性。task-14 负责接通真实队列入口、UI线程调度与独立任务命令。
- 绿色升级：生产代码无 UpdateAsync 调用；显式回退未先持久化恢复日志，回执写失败后丢失恢复依据；恢复路径未充分关联所属安装，可能改动无关同级目录；新升级可能覆盖未解决日志；回退后刷新因忙碌标记早退。task-16 负责事务、路径授权、升级入口、状态与回归。
- 7z：旧 tar 路径错误输出未读取、标准输出无界、取消不终止进程；仅列文件名不能在写盘前限制链接和展开量。task-15 删除不安全路径，所有 .7z 在下载前返回明确不支持。**本轮暂不提供 7z 自动解压**，不能宣称与 ZIP 同级保护。未来需经过验证的有界流式解压实现。
- 库维护：原导出拒绝无来源证据的手动条目、仅保留一个发行版、DescriptionOverride 不能正确读回；界面逐条 GetAppAsync 可能联网且吞异常遗漏条目。task-17 新增完整离线快照与独立本地备份格式，保留手动条目和全部发行快照；公开同步库仍要求证据，不把本地备份当成公开核验来源。
- 规则编辑：新增设置页现有条目的渠道/固定标签/分架构包含排除规则/格式/程序路径/保留路径编辑。修改后须重新预览；预览明确基于本地快照，保存联网核对并原子提交，不安装软件。

- 设置页真实存在“检查配置问题／导出软件库／载入现有条目”和规则编辑折叠区；预览前保存按钮禁用、预览后启用。

### 本轮修复的实质缺陷

- 下载队列：后台事件跨线程改界面集合、`ConfigureAwait(false)` 后更新界面、模板跨名称作用域取父命令、任务缺少本地化对象；关闭时未等工作循环结束就释放同步原语；未预期异常会让任务永远停在下载中并使暂停永久等待。
- 绿色升级：`UpdateAsync` 无任何生产调用方（功能实际不可用）；显式回退未先持久化恢复日志，回执写失败后失去恢复依据；被替换目录在登记成功前就被删除；恢复/回退只按前缀识别同级目录，可被改成邻居目录名后改动他人文件；新升级会覆盖未解决日志；回退后刷新因忙碌标记早退；更新失败提示被自动刷新清空。
- 7z：旧外部 `tar` 路径无法在写盘前限制链接与展开量，错误输出未读取会阻塞、标准输出无界、取消不终止进程。**已移除该危险路径，7z 在下载前明确拒绝**。
- 库维护：原导出拒绝手动条目、只保留一个发行版、描述覆盖读不回；界面逐条联网取详情且吞异常漏条目。现改为一次离线快照 + 独立本地备份格式。

### 尚未完成/仍有限制

- 7z 自动解压、外部 EXE/MSI 应用升级、差分更新、并行下载、aria2 断点续传、Authenticode 验证、后台静默更新。
- 库配置的保留路径（PreservePaths）不做保留式升级：声明了保留路径的更新会被**明确拒绝**，而不是默默覆盖用户配置。
- 旧版（schema 1）恢复日志 fail closed：保留原样并报告，需人工核对，不自动处理。
- 本地备份格式的解析 API 已提供，但界面尚未提供导入入口。

并行写入范围：task-14 持有 DownloadsViewModel 与 CatalogView；task-15 持有 AppInstallService 与安装测试；task-16 持有 PortableUpgradeService、InstalledViewModel/InstalledView、App启动恢复与相关测试；task-17 持有 Core 导出/离线快照与相关测试。Lead 持有 Settings、库编辑器、本地化、DI、测试项目链接及文档；所有构建串行协调。

## 验收约定

- 先串行编译测试项目，再使用 in-process xUnit runner；另行构建完整WinUI客户端。
- 针对真实故障写回归，不以数量替代覆盖范围。
- UI与安装验收仅使用独立测试数据目录和专用测试软件，不改用户已有软件。
- 未实现的能力明确标注：7z自动解压、外部EXE/MSI应用升级、差分更新、并行下载、aria2续传、Authenticode验证、后台静默更新。
- 本地备份解析API不等同于已提供GUI备份导入；离线诊断不等同于已检查上游链接存活。
