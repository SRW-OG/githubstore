# 软件管理优化实施记录

用户要求按顺序完成全部八项优化。此文件保存目标、验收依据和交接信息；未验证的能力不得标记完成。

## 顺序与验收

1. **库配置控制默认版本与包**：支持正式/预发布/固定版本、分架构包含和排除文件名规则、安装格式和主程序相对路径；更新库可改变推荐；旧库兼容；规则失配明确反馈；平台/架构检查不可绕过。
2. **手工添加向导**：仓库预览后确认版本策略、包、分类、介绍及安装方式；配置持久保存和刷新保留；可选 AI 生成基于真实资料的建议，由用户确认；无 AI 可完成。
3. **安装状态核对**：分别展示可运行、文件缺失、卸载登记缺失/不可读；提供刷新、定位主程序和仅移除记录；不以登记缺失推断已卸载。
4. **更新与可靠绿色升级**：显示已装/候选版本，确认后下载校验、暂存检查、保留旧目录、切换及失败恢复；保留配置依据由库声明；外部安装器遵循自己的升级机制。
5. **压缩包安装**：7z 与 ZIP 同等级路径/链接/展开量保护，主程序配置优先且必须验证，多层目录识别；不明确时用户选择。
6. **下载管理**：队列、暂停恢复、重试、可信续传与校验；保持 HTTP/外部引擎行为清晰；异常时不破坏已有完整文件。
7. **商店自身更新**：显示当前/新版本与发行说明，校验官方安装包，用户确认后启动升级；不静默更新。
8. **库维护工具**：界面编辑、完整验证和导出；检查规则失配、无发行包、链接失效；本地配置和共享库来源清楚。
9. **集成交付**：有意义的回归测试、Windows x64 编译、安装包、最终源码复核，按已授权发布到仓库。
