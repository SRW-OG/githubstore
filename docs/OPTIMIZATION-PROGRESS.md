# 软件管理优化实施记录

## 当前轮次：0.1.7 发布后可靠性优化

用户已授权继续优化。上一轮的“八项全部完成”结论过强：测试与编译通过不能证明界面接通、故障恢复或真实安装已验收。本轮以实际代码审查、针对性回归与界面验收为准。

### 已确认的问题与处理

- 下载队列：后台事件直接修改 ObservableCollection 和界面属性；原“仅下载”仍走单次下载，模板跨名称作用域取父命令，任务对象没有 Text 属性。task-14 负责接通真实队列入口、UI线程调度与独立任务命令。
- 绿色升级：生产代码无 UpdateAsync 调用；显式回退未先持久化恢复日志，回执写失败后丢失恢复依据；恢复路径未充分关联所属安装，可能改动无关同级目录；新升级可能覆盖未解决日志；回退后刷新因忙碌标记早退。task-16 负责事务、路径授权、升级入口、状态与回归。
- 7z：旧 tar 路径错误输出未读取、标准输出无界、取消不终止进程；仅列文件名不能在写盘前限制链接和展开量。task-15 删除不安全路径，所有 .7z 在下载前返回明确不支持。**本轮暂不提供 7z 自动解压**，不能宣称与 ZIP 同级保护。未来需经过验证的有界流式解压实现。
- 库维护：原导出拒绝无来源证据的手动条目、仅保留一个发行版、DescriptionOverride 不能正确读回；界面逐条 GetAppAsync 可能联网且吞异常遗漏条目。task-17 新增完整离线快照与独立本地备份格式，保留手动条目和全部发行快照；公开同步库仍要求证据，不把本地备份当成公开核验来源。
- 规则编辑：新增设置页现有条目的渠道/固定标签/分架构包含排除规则/格式/程序路径/保留路径编辑。修改后须重新预览；预览明确基于本地快照，保存联网核对并原子提交，不安装软件。

## 验收约定

- 先串行编译测试项目，再使用 in-process xUnit runner；另行构建完整WinUI客户端。
- 针对真实故障写回归，不以数量替代覆盖范围。
- UI与安装验收仅使用独立测试数据目录和专用测试软件，不改用户已有软件。
- 未实现的能力明确标注：7z自动解压、外部EXE/MSI应用升级、差分更新、并行下载、aria2续传、Authenticode验证、后台静默更新。
- 本地备份解析API不等同于已提供GUI备份导入；离线诊断不等同于已检查上游链接存活。
